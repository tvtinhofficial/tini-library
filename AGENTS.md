## Lập trình web

### Công cụ cho AI lập trình

- **Graphify-Labs/graphify** (repo) — https://github.com/Graphify-Labs/graphify
  - What: Biến toàn bộ dự án (code, tài liệu, PDF, ảnh, video) thành đồ thị tri thức để AI tra cứu thay vì đọc lại từng file.
  - When: Khi dự án code lớn khiến AI tốn token và hay quên cấu trúc.
  - Install: `uv tool install graphifyy && graphify install`
  - Phân tích code chạy cục bộ bằng tree-sitter, không gửi code đi đâu
  - Xuất graph.html để click xem, GRAPH_REPORT.md tóm tắt và graph.json để truy vấn
  - Mỗi liên kết được gắn nhãn đọc trực tiếp (EXTRACTED) hay suy luận (INFERRED)
  - Dùng được với Claude Code, Cursor, Codex, Gemini CLI và hơn 20 trợ lý khác

- **morluto/rea** (repo) — https://github.com/morluto/rea
  - What: REA (Reverse Engineer Anything): một MCP giúp AI agent tìm hiểu cách một tính năng hoạt động trong ứng dụng không có mã nguồn, kèm bằng chứng.
  - When: Khi muốn hiểu một tính năng của app khác để làm bản tương tự; chỉ dùng trong phạm vi điều khoản và luật cho phép.
  - Install: `npx rea-agents setup`
  - Phân tích file nhị phân, app JavaScript/Electron, .NET và website
  - Chạy cục bộ, kết quả có bằng chứng và giới hạn cho từng kết luận
  - Cài một lệnh cho Claude Code, Codex, Cursor, Gemini CLI
